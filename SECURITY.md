# Security

If you find a security problem in PortPerson, please don't post details publicly. Open a GitHub issue that says you have a security report (without the details), or use GitHub's "Report a vulnerability" option if it's enabled, and you'll get a way to share it privately.

PortPerson collects no user data and has no servers, so most reports will be about the app's handling of network traffic or files on the phone.
